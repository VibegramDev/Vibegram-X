# Material 3 Expressive в Vibegram X

Практический источник истины для редизайна. Правила берутся из текста официальных страниц
[m3.material.io](https://m3.material.io/), а не только из токенов. Значения токенов (dp, пружины)
берутся из `androidx.compose.material3.tokens` и помечаются как таковые.

Метки: **MUST** — требование или Don't на сайте, **SHOULD** — рекомендация, **MAY** — допустимо,
**наше** — решение проекта (не требование гайдлайна).

## 1. Неизменяемое

Расположение и состав главной навигации задаёт владелец продукта; структура меняется только по его запросу:

- **Телефон:** плавающий вертикальный док справа внизу: «Поиск» (лупа ↔ ✕), «Чаты», «Звонки», «Контакты»,
  «Настройки» (аватар). Только иконки. При прокрутке списка сворачивается в стрелку «Наверх».
- **Планшет (две панели):** нижняя панель внутри левой панели списка, с подписями: «Чаты», «Звонки»,
  «Контакты», «Настройки». Пункта «Поиск» нет — поиск открывается пилюлей под шапкой. Не сворачивается.
- **«Написать»** — карандаш в шапке главного экрана (меню: новый чат, группа, канал, секретный чат), не в доке
  и не FAB.
- **Шапка главного экрана:** без вкладок и без линии тени; на телефоне заголовок «Vibegram X» и эмодзи-статус.
  Вкладки папок в шапке не стоят никогда (расположение папок — раздел 7).

Свободно меняется только стилистика: цветовые роли, индикатор, иконки, бейджи, состояния, шрифты, анимация.
Док не заменяется официальными navigation bar / rail.

## 2. Решения

Подтверждены владельцем продукта:

- Геометрия дока (раздел 1).
- Боковое меню (drawer) отключено целиком и не редизайнится: кнопки-гамбургера на главном экране нет,
  свайп и программное открытие заблокированы (`MainController.getBackButton() = TYPE_NONE`,
  `useDrawer() = false`). Код `DrawerController` оставлен, но не используется. Входы, которые были только в
  меню и сейчас недоступны: переключение между уже добавленными аккаунтами, «Пригласить друзей», «Сообщить
  об ошибке», переключатели функций, логи TDLib. Добавить аккаунт и выйти можно через Настройки → ⋮ → «Выйти».
  Прокси, ночной режим, помощь, Избранное, Контакты и Звонки доступны из настроек, дока и вкладок.
- Бейдж непрочитанных на «Чатах» остаётся видимым, даже когда «Чаты» выбраны — осознанное отклонение от SHOULD
  «hide the badge once the destination has been selected» ([Badges](https://m3.material.io/components/badges)):
  иначе на телефоне число непрочитанных не видно нигде, кроме вкладки.
- Правила берутся из текста m3.material.io; этот документ ведётся в репозитории.

Рабочие варианты по умолчанию (предложены, явно не подтверждены; гайдлайн оставляет выбор продукту):

- Список чатов — обычный (standard) expressive list без карточек на строку, на всю ширину **своей панели**
  (SHOULD «Lists should extend edge-to-edge in compact windows», [Lists](https://m3.material.io/components/lists)).
- Аватары круглые (shape library для аватаров — MAY).
- Настройки — сгруппированные (segmented) списки.
- Меню — standard, не vibrant (vibrant — «sparingly»).

## 3. Отклонения, принятые из-за фиксированного дока

- На телефоне у пунктов дока нет подписей. На сайте это MUST: «Don't remove the labels from navigation items»
  ([Navigation bar](https://m3.material.io/components/navigation-bar)). Сейчас у каждого пункта есть
  contentDescription с названием раздела. План компенсации: зачитывать число из бейджа после названия и
  показывать подсказку по долгому нажатию (ещё не сделано).
- Док закрывает правый край строк списка во время прокрутки. Это компромисс выбранного floating-дизайна,
  а не ограничение платформы. Смягчение: нижний отступ списка, чтобы любую строку можно было прокрутить выше дока.
- Бар на планшете стоит внутри панели, хотя для expanded-окон сайт рекомендует rail вне панелей (SHOULD).

## 4. Роли цветов

Источник: [Color roles](https://m3.material.io/styles/color/roles). Пары используются только так, как задумано
(MUST): container — заливка, on-container — текст и иконки поверх неё.

| Элемент | Роль |
|---|---|
| Фон списка, шапок, настроек, чата (Monet Dark) | `surface` (системная роль Android 14+, `sys(surface_dark,…)` в шаблоне) |
| Шапка главного экрана при прокрутке | `surface` → `surfaceContainer`, без тени ([App bars](https://m3.material.io/components/app-bars): MUST) |
| Нижняя панель на планшете | `surfaceContainer` |
| Плавающий док на телефоне | `surfaceContainerHigh` в тёмной теме, `surfaceContainer` в светлой (**наше**: в тёмной теме тень почти не видна) |
| Индикатор выбранного пункта | `secondaryContainer`, иконка `onSecondaryContainer`, подпись `secondary` + bold |
| Невыбранные пункты | контурная иконка и подпись `onSurfaceVariant` |
| Пункт «Поиск» в доке телефона | закрыт — как невыбранный пункт; поиск открыт — индикатор `secondaryContainer`, иконка ✕ `onSecondaryContainer` |
| FAB / пункты FAB-меню (`M3FabView`, сейчас не используются) | `primaryContainer` / `onPrimaryContainer`; открыт — `primary` / `onPrimary` |
| Бейджи навигации (док, вкладки) | `error` / `onError` (SHOULD «Keep the default color mapping»); отключённые чаты — нейтральный бейдж |
| Счётчики в строках чатов | `primary`-тона; отключённые — `secondaryContainer` / `onSecondaryContainer` (**наше**; на странице Badges счётчики строк не описаны) |
| Активная вкладка | `primary`; неактивные — `onSurfaceVariant` |

Старые темы (не Monet) получают роли приближённо, смешиванием цветов темы (`M3.computeDerived`).

## 5. Шрифты

Источник: [Typography](https://m3.material.io/styles/typography).

- Компоненты по умолчанию baseline; emphasized — для выбранного, действий и **непрочитанного** (SHOULD).
- Имя чата: обычное начертание у прочитанных, жирное у непрочитанных (только в темах Monet; в старых темах
  имена остаются жирными).
- Не утяжелять мелкий текст (MUST: «Excessive weight at smaller sizes»).

## 6. Анимация

Источник: [Motion](https://m3.material.io/styles/motion/overview), [Transitions](https://m3.material.io/styles/motion/transitions).

- Пружины: spatial (положение, размер, форма) — с перелётом; effects (цвет, прозрачность) — без перелёта.
  Для каждого типа свой аниматор.
- Мелкие компоненты: fast spatial / fast effects. Числа пружин на сайте не указаны, берутся из токенов
  (`M3.FAST_SPATIAL`, `M3.FAST_EFFECTS`, `M3.DEFAULT_*`).
- FAB-меню (код `OverlayButtonWrap`, сейчас не используется): пункты выезжают по оси Y и проявляются;
  масштабирование не используется («Scale and z-axis motion is avoided»).
- `M3.Spring` — приближение пружины через длительность: при прерывании скорость не сохраняется.
- Пункт «Поиск» в доке следует фактору поиска шапки (`applySearchTransformFactor`): индикатор и поворот
  лупы ↔ ✕ идут вместе с анимацией шапки, а не по пружинам M3.

## 7. Реализовано

- `theme/M3.java` — роли цветов, шкала скруглений, уровни теней, пружины.
- `ThemeMonet` — функция шаблона `sys(role,fallback)`: системная роль Android 14+.
- `MainNavigationBar` — роли, индикатор, контурные/залитые иконки, бейдж, пункт «Поиск» (лупа ↔ ✕),
  сворачивание в «Наверх» (`ITEM_SCROLL_TOP`).
- `OverlayButtonWrap`, `M3FabView` — FAB и FAB-меню, раздельные spatial/effects-пружины. Сейчас не
  используются: «Написать» переехал в шапку; код оставлен.
- `ChatsController` / `MainController` — нижний отступ списка под доком/FAB, цвет шапки при прокрутке.
- `TGChat` — начертание имени по непрочитанным.
- `ViewPagerTopView` — индикатор вкладок 3dp со скруглением сверху по ширине текста, подписи без капслока.
- `M3SettingsGroupDecoration` — сгруппированные (segmented) списки настроек: внешние углы 16dp, внутренние 4dp,
  промежутки 2dp, тени и разделители заменены цветом страницы, группы считаются по модели адаптера.
  Подключается `M3SettingsGroupDecoration.attach(recyclerView, adapter)` до `setAdapter`. Включено на главном
  экране настроек, «Данные и память», «Уведомления и звуки», «Конфиденциальность»; только в темах Monet.
  Фон строки оборачивается (исходный drawable хранится внутри обёртки) и возвращается при откреплении строки
  (recycling) и при выходе из Monet; при смене Monet ↔ старая тема отступы пересчитываются.
  `TYPE_INFO` (текст на подложке) — тоже сегмент. Перед подключением нового экрана проверить, что все его
  типы строк есть в `kindAt()`.
- Цвета групп: страница — `background` (Monet White: `surfaceContainer`, тон ~94; Dark: `surface`, тон 4),
  строки — `surfaceContainerLowest` (светлая) / `surfaceContainerHigh` (тёмная). Изменение `background`
  в светлой теме затрагивает все экраны, где он используется (фон настроек, полосы-разделители в списке чатов).
- `TogglerView` — переключатель M3 (трек 52×32dp, ручка 16/24dp, 28dp при нажатии строки, без тени) во всех
  местах приложения в темах Monet; варианты с замком и «негативным» состоянием остаются старыми. Ширина
  переключателя в `SettingView`: 72dp в Monet, 66dp (как было) в старых темах; при смене темы строка
  пересчитывает ширину и место под текст. Обработка нажатий не менялась.
- `ViewPagerHeaderViewCompact.setM3Divider` — разделитель вкладок 1dp `outlineVariant` под индикатором
  (по нижнему краю полосы вкладок), включён только для главной шапки, только в Monet.

- Главный экран (шапка и док), только `MainController` и новые виджеты; общие `HeaderView`/`HeaderFilling`
  меняются только через флаги экрана (`useHeaderShadowLine`, сдвиг `moreWrap` на `trailingGap`):
  - телефон: шапка — `M3MainTitleView` («Vibegram X» + эмодзи-статус, по умолчанию 🚀) и карандаш с меню
    «Написать»; док `MainNavigationBar` — плавающий вертикальный: Поиск → Чаты → Звонки → Контакты →
    Настройки (аватар). При прокрутке списка док сворачивается в стрелку ↑ (`ITEM_SCROLL_TOP`), а Поиск,
    Звонки, Контакты и аватар переезжают в шапку перед карандашом (`mainMenus`, обновляются во всех меню —
    у левой панели планшета своё меню). На узкой ширине заголовок уступает место: сначала прячется эмодзи,
    потом шрифт 22 → 18sp, потом заголовок скрывается целиком;
  - планшет: шапка левой панели — пилюля поиска `M3SearchBarView` (48dp вместо 56dp, чтобы влезть в шапку
    56dp) и карандаш; док — горизонтальная панель внизу панели списка, не сворачивается. Подсветка нажатия
    пунктов дока обрезается по пилюле индикатора;
  - «Звонки» — раздел через `CallListController`.
- Папки чатов (`getFoldersPlacement()` в `MainController`): вкладки папок никогда не стоят в шапке.
  Телефон — всегда внизу экрана, док стоит над ними и уезжает вместе с панелью при прокрутке. Планшет —
  на выбор в «Папки с чатами → Внешний вид» (флаг `ChatFolderOptions.TABLET_DISPLAY_BELOW_SEARCH`, на аккаунт):
  сбоку — рейл `M3FolderRailView` (80dp, иконка + подпись, индикатор 56×32, следует за пейджером) слева во всю
  высоту; ширина списка не меняется, рейл забирает ширину у правой панели (`TabletLayoutPolicy.masterWidth`,
  справа ≥ 360dp); под поиском — полоса вкладок под шапкой (`topTabsBar`). Старая галочка «папки сверху» из
  диалога убрана, глобальный фильтр в шапке отключён (`useGlobalFilter()` → false). Первая вкладка —
  значок и «Все» (`CategoryMainShort`).
- `res/values-ru/strings.xml` — русские строки, которых нет в облачном языковом пакете (новые строки
  редизайна: `ScrollToTop`, `CategoryMainShort`, пункты расположения папок).

## 8. План

Отложено решением владельца продукта: поддержка системного размера шрифта (`font_scale`) в списке чатов и
шапке. Сейчас Telegram X его не учитывает (высота строки и подписи вкладок одинаковы при 1.08 и 2.0) — это
расхождение с требованиями доступности M3, не трогать до отдельного решения.

1. Настройки: перевести остальные экраны на `M3SettingsGroupDecoration` (проверяя типы строк каждого экрана),
   проверить Monet Black, RTL, старые темы (ширина переключателя 66dp) и светлую тему на «Уведомлениях» и
   «Конфиденциальности». Готовность остальных экранов по типам строк в коде (grep по файлу; один контроллер
   может строить разные наборы строк, поэтому каждый экран проверять на устройстве):
   - все типы уже есть в `kindAt()`: Proxy, Cloud, LanguageTranslate;
   - мешают только пустые строки-отступы (`TYPE_EMPTY`, `TYPE_EMPTY_OFFSET_SMALL`): Language, PrivacyKey,
     StickersAndEmoji, ArchiveChatList, LogFiles;
   - свои типы строк, решать по экрану: Theme (`TYPE_SLIDER_BRIGHTNESS`), Sessions/Websites (строки сессий),
     Blocked (`TYPE_USER`), Cache, LogOut (`TYPE_CHAT_BETTER`), Folders (`TYPE_CUSTOM`, `TYPE_PADDING`);
   - формы, скорее всего не группировать: 2FA, Phone (поля ввода, кнопки), Bug.
2. Поиск. Сделано: вход в поиск (пилюля в шапке планшета, пункт дока на телефоне, лупа ↔ ✕ в доке).
   Не сделано: сам режим поиска по M3 (ниже). Как устроено сейчас: поиск главного экрана — режим
   `TRANSFORM_MODE_SEARCH` общего `HeaderView`; поле `HeaderEditText` (отступы 68dp слева / 49dp справа,
   высота шапки 56dp) создаёт `ViewController.genSearchHeader`; цвет шапки в поиске — `getSearchHeaderColor()`
   (сейчас `final`); список результатов — `generateChatSearchView`, общий с `ChatsController`,
   `HashtagController`, `ContactsController`. Цель по [Search](https://m3.material.io/components/search):
   contained full-screen — контейнер `surfaceContainerLow`, строка поиска 56dp, полностью скруглённая,
   `surfaceContainerHigh`, отступы 16dp, back и clear внутри строки. Риск: «пилюлю» строки придётся рисовать
   в `HeaderFilling`/`HeaderView` (общие для всех экранов) — делать опционально через флаг экрана и только
   для главного экрана. Широкое окно: панель списка ~326dp меньше минимума docked search (360dp) —
   оставить full-screen внутри панели как адаптацию. Тесты: ввод, очистка, IME, открыть результат и назад,
   пустой результат, compact ↔ split с активным поиском, регрессия раздела 9.
3. Меню, диалоги (28dp, ≤ 2 действий), нижние шторки (28dp, ≤ 50% высоты), snackbar, индикатор загрузки.
4. Переходы между экранами, подсказки и доступность дока.

## 9. Регрессии

### Меню карандаша на планшете открывается у правого края окна (открыто)

- В двух панелях меню «Написать» (`showMore` из `MainController`) появляется у правого края всего окна, а не
  рядом с карандашом в шапке левой панели. Замечено в итерации 5; в этой сессии заново не воспроизводилось,
  не исправлено.

### Вылет при переходе на «Контакты» после смены режима окна (исправлено)

- Стек: `NullPointerException: TextView.setId` в `HeaderView.genTitle` ← `HeaderView.setTitle` ←
  `NavigationController.navigateTablet` ← `MainController.openNavigationSection` (пункт «Контакты»).
- Минимальный сценарий: узкое окно → открыть «Настройки» и остаться → раскрыть до двух панелей → «Контакты».
- Причина: `applyPreview()` меняет местами `textTitle`/`textPreview`. После перехода между двумя экранами со
  своей шапкой (Чаты → Настройки) обычный текстовый заголовок становится `null`. Анимированный путь создаёт
  его заново в `genPreview()`, а путь двух панелей (`navigateTablet → setTitle → genTitle`) — нет.
  Это дефект существующего кода планшетной навигации (`HeaderView`/`NavigationController` редизайном не
  менялись), проявившийся при смене режима; историческую сборку отдельно не проверяли.
- Исправление: `HeaderView.genTitle` создаёт `textTitle`, если его нет (как `genPreview` для `textPreview`).
- Проверено на Fold сменой размера окна (`wm size`), не физическим складыванием: сценарий выше; Настройки ↔
  Контакты ×2 → Чаты в двух панелях; узкое окно Настройки → Back → Настройки → раскрыть → Контакты;
  Контакты → узкое окно → Back → раскрыть → Настройки → Контакты → Back. Падений нет, у «Контактов»
  заголовок и кнопка «Назад» на месте.

### Вылет после входа: `UnsupportedOperationException` в `ViewPagerTopView.setItemAt` (исправлено)

- Список вкладок без папок был `Collections.singletonList`, а счётчик непрочитанных при смене ширины
  вызывает `List.set`. Список вкладок для `ViewPagerTopView` должен быть изменяемым (`ArrayList`).

### Иконки дока не переезжали в шапку после складывания/раскладывания Fold (исправлено)

- Код помнил только последнее меню шапки; у левой панели планшета своя шапка. Кнопки обновляются во всех
  `mainMenus` по id. Проверка: `adb shell cmd device_state state 0|3`, затем `state reset`.

## 10. Тестовая матрица

- Устройство: Galaxy Z Fold; телефон — окно `wm size 1200x1848` (~457dp), планшет — раскрытый экран (~932dp).
  Раскладку телефона проверять на нескольких плотностях (например `wm size 1000x1848` при 420/444/500 dpi):
  Fold шире обычного телефона. Складывание эмулировать `cmd device_state state 0|3`, затем `state reset`.
- Темы: Monet White / Dark / Black, хотя бы одна старая тема.
- Проверки: выбранный чат в двух панелях, непрочитанный → прочитанный, архив, папки, прокрутка до конца,
  возврат из настроек, открытие и закрытие поиска с клавиатурой, крупный шрифт.
- Перед тестом сохранить и после восстановить `wm size`, `wm density`, `font_scale`, ночной режим.
- Цвета сверять по пикселям скриншотов, а не на глаз.

## 11. Как получить текст гайдлайнов

m3.material.io — одностраничное приложение; текст страниц приходит JSON-ом из
`/_dsm/content/m3/<carbonVersion>/<fileId>.json`, таблица страниц и версия — в `/static/angular/main.*.js`.
Скрипт загрузки в Markdown хранится вне репозитория (навык Hermes `material3-guidelines`).
