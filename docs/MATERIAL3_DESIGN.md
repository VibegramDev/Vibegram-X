# Material 3 Expressive в Vibegram X

Практический источник истины для редизайна. Правила берутся из текста официальных страниц
[m3.material.io](https://m3.material.io/), а не только из токенов. Значения токенов (dp, пружины)
берутся из `androidx.compose.material3.tokens` и помечаются как таковые.

Метки: **MUST** — требование или Don't на сайте, **SHOULD** — рекомендация, **MAY** — допустимо,
**наше** — решение проекта (не требование гайдлайна).

## 1. Неизменяемое

Расположение и состав главной навигации задаёт владелец продукта; структура меняется только по его запросу:

- **Телефон:** плавающий вертикальный док справа внизу: «Поиск» (лупа ↔ ✕), «Чаты», «Звонки», «Контакты»,
  «Настройки» (аватар). Только иконки. При прокрутке списка сворачивается в стрелку «Наверх».
- **Планшет (две панели):** нижняя панель внутри левой панели списка, с подписями: «Чаты», «Звонки»,
  «Контакты», «Настройки». Пункта «Поиск» нет — поиск открывается пилюлей под шапкой. Не сворачивается.
  Панель плавающая (решение владельца): высота 64dp, радиус 23dp — концентричен индикатору (радиус индикатора
  16dp + 7dp от верхнего края; `MainNavigationBar.getBarRadius`), отступы 12dp по бокам и снизу
  (над системной навигацией), внутренние поля 8dp, `surfaceContainer`. Тень мягкая, рисует `M3BottomScrimView` (два слоя: 6dp/смещение 2dp и
  1.5dp/0.5dp, 12% и 8% чёрного; в тёмной теме 40% и 30%), без системной elevation.
  Список прокручивается под панель (нижний отступ списка = 64 + 12 + 8dp). Под панелью — scrim
  `M3BottomScrimView`: прозрачный → `surface` на 24dp над панелью, ниже непрозрачный, чтобы строки не
  проступали вокруг панели.
- **Чат (решение владельца):** фон без обоев — `surface`, как у остальных экранов (`chatBackground` в
  `Theme.chromeColor`, `WallpaperView`). Поле ввода с кнопками — `surfaceContainer`, как док; текст `onSurface`,
  плейсхолдер и иконки `onSurfaceVariant` (`MessagesController.applyComposerContentColors`), линия над полем
  убрана. Планшет (чат в правой панели): поле плавающее, как панель дока — 64dp, радиус 23dp, отступы 12dp, та
  же тень и тот же фейд (`M3BottomScrimView`, сообщения прокручиваются под поле), кнопки по центру (`checkComposerLayout`, вызывается из `MessagesLayout.onMeasure`); панель ответа выезжает над полем
  тем же контейнером (скруглён верх, у поля верхние углы уходят в 0 по мере появления). Телефон — поле
  прижато к низу на всю ширину.
- **«Написать»** — карандаш в шапке главного экрана (меню: новый чат, группа, канал, секретный чат), не в доке
  и не FAB.
- **Шапка главного экрана:** без вкладок и без линии тени; на телефоне заголовок «Vibegram X» и эмодзи-статус.
  Вкладки папок в шапке не стоят никогда (расположение папок — раздел 7).

Свободно меняется только стилистика: цветовые роли, индикатор, иконки, бейджи, состояния, шрифты, анимация.
Док не заменяется официальными navigation bar / rail.

## 2. Решения

Подтверждены владельцем продукта:

- Геометрия дока (раздел 1).
- Боковое меню (drawer) отключено целиком и не редизайнится: кнопки-гамбургера на главном экране нет,
  свайп и программное открытие заблокированы (`MainController.getBackButton() = TYPE_NONE`,
  `useDrawer() = false`). Код `DrawerController` оставлен, но не используется. Входы, которые были только в
  меню и сейчас недоступны: переключение между уже добавленными аккаунтами, «Пригласить друзей», «Сообщить
  об ошибке», переключатели функций, логи TDLib. Добавить аккаунт и выйти можно через Настройки → ⋮ → «Выйти».
  Прокси, ночной режим, помощь, Избранное, Контакты и Звонки доступны из настроек, дока и вкладок.
- Бейдж непрочитанных на «Чатах» остаётся видимым, даже когда «Чаты» выбраны — осознанное отклонение от SHOULD
  «hide the badge once the destination has been selected» ([Badges](https://m3.material.io/components/badges)):
  иначе на телефоне число непрочитанных не видно нигде, кроме вкладки.
- Правила берутся из текста m3.material.io; этот документ ведётся в репозитории.
- **Один интерфейс M3 для всех тем.** Выбор темы меняет только цветовую схему; компоненты, геометрия, шрифты,
  состояния и анимация одинаковы в Monet, старых встроенных и пользовательских темах. От темы зависит только
  источник палитры (`M3.compute`: системные роли Android 14+ для Monet, производные роли для остальных).
  Проверки вида «это Monet?» в коде интерфейса запрещены.
- Фон экранов и шапка во всех темах — роль `surface`, карточки и навигация — `surfaceContainer`, цвета
  header*/filling/background пресета в интерфейсе не используются (решение владельца, отменяет прежнее «цветная
  шапка сохраняется»; подробности — раздел о главном экране, `Theme.chromeColor`). При прокрутке шапка цвет не
  меняет (решение владельца).
- Меню карандаша («Написать») в двух панелях открывается у правого края окна — так и задумано, не дефект
  (решение владельца).

Рабочие варианты по умолчанию (предложены, явно не подтверждены; гайдлайн оставляет выбор продукту):

- Список чатов — обычный (standard) expressive list без карточек на строку, на всю ширину **своей панели**
  (SHOULD «Lists should extend edge-to-edge in compact windows», [Lists](https://m3.material.io/components/lists)).
- Аватары круглые (shape library для аватаров — MAY).
- Настройки — сгруппированные (segmented) списки.
- Меню — standard, не vibrant (vibrant — «sparingly»).

## 3. Отклонения, принятые из-за фиксированного дока

- На телефоне у пунктов дока нет подписей. На сайте это MUST: «Don't remove the labels from navigation items»
  ([Navigation bar](https://m3.material.io/components/navigation-bar)). Сейчас у каждого пункта есть
  contentDescription с названием раздела. План компенсации: зачитывать число из бейджа после названия и
  показывать подсказку по долгому нажатию (ещё не сделано).
- Док закрывает правый край строк списка во время прокрутки. Это компромисс выбранного floating-дизайна,
  а не ограничение платформы. Смягчение: нижний отступ списка, чтобы любую строку можно было прокрутить выше дока.
- Бар на планшете стоит внутри панели, хотя для expanded-окон сайт рекомендует rail вне панелей (SHOULD).

## 4. Роли цветов

Источник: [Color roles](https://m3.material.io/styles/color/roles). Пары используются только так, как задумано
(MUST): container — заливка, on-container — текст и иконки поверх неё.

| Элемент | Роль |
|---|---|
| Фон списка, шапок, настроек, чата (Monet Dark) | `surface` (системная роль Android 14+, `sys(surface_dark,…)` в шаблоне) |
| Шапка главного экрана при прокрутке | Гайдлайн: `surface` → `surfaceContainer`, без тени ([App bars](https://m3.material.io/components/app-bars): MUST). У нас — цвет не меняется (решение владельца, отступление), тени нет |
| Нижняя панель на планшете | `surfaceContainer` |
| Плавающий док на телефоне | `surfaceContainerHigh` в тёмной теме, `surfaceContainer` в светлой (**наше**: в тёмной теме тень почти не видна) |
| Индикатор выбранного пункта | `secondaryContainer`, иконка `onSecondaryContainer`, подпись `secondary` + bold |
| Невыбранные пункты | контурная иконка и подпись `onSurfaceVariant` |
| Пункт «Поиск» в доке телефона | закрыт — как невыбранный пункт; поиск открыт — индикатор `secondaryContainer`, иконка ✕ `onSecondaryContainer` |
| Режим поиска главного экрана | вид `surfaceContainerLow`, строка поиска `surfaceContainerHigh`, текст и иконки `onSurface` |
| FAB / пункты FAB-меню (`M3FabView`, сейчас не используются) | `primaryContainer` / `onPrimaryContainer`; открыт — `primary` / `onPrimary` |
| Бейджи навигации (док, вкладки) | `error` / `onError` (SHOULD «Keep the default color mapping»); отключённые чаты — нейтральный бейдж |
| Счётчики в строках чатов | `primary`-тона; отключённые — `secondaryContainer` / `onSecondaryContainer` (**наше**; на странице Badges счётчики строк не описаны) |
| Активная вкладка | `primary`; неактивные — `onSurfaceVariant` |

Старые темы (не Monet) получают роли приближённо, смешиванием цветов темы (`M3.computeDerived`); интерфейс
у них тот же (раздел 2). Шапка при прокрутке цвет не меняет (решение владельца).

## 5. Шрифты

Источник: [Typography](https://m3.material.io/styles/typography).

- Компоненты по умолчанию baseline; emphasized — для выбранного, действий и **непрочитанного** (SHOULD).
- Имя чата: обычное начертание у прочитанных, жирное у непрочитанных (во всех темах).
- Не утяжелять мелкий текст (MUST: «Excessive weight at smaller sizes»).

## 6. Анимация

Источник: [Motion](https://m3.material.io/styles/motion/overview), [Transitions](https://m3.material.io/styles/motion/transitions).

- Пружины: spatial (положение, размер, форма) — с перелётом; effects (цвет, прозрачность) — без перелёта.
  Для каждого типа свой аниматор.
- Мелкие компоненты: fast spatial / fast effects. Числа пружин на сайте не указаны, берутся из токенов
  (`M3.FAST_SPATIAL`, `M3.FAST_EFFECTS`, `M3.DEFAULT_*`).
- FAB-меню (код `OverlayButtonWrap`, сейчас не используется): пункты выезжают по оси Y и проявляются;
  масштабирование не используется («Scale and z-axis motion is avoided»).
- `M3.Spring` — приближение пружины через длительность: при прерывании скорость не сохраняется.
- Пункт «Поиск» в доке следует фактору поиска шапки (`applySearchTransformFactor`): индикатор и поворот
  лупы ↔ ✕ идут вместе с анимацией шапки, а не по пружинам M3.

## 7. Реализовано

- `theme/M3.java` — роли цветов, шкала скруглений, уровни теней, пружины.
- `ThemeMonet` — функция шаблона `sys(role,fallback)`: системная роль Android 14+.
- `MainNavigationBar` — роли, индикатор, контурные/залитые иконки, бейдж, пункт «Поиск» (лупа ↔ ✕),
  сворачивание в «Наверх» (`ITEM_SCROLL_TOP`).
- `OverlayButtonWrap`, `M3FabView` — FAB и FAB-меню, раздельные spatial/effects-пружины. Сейчас не
  используются: «Написать» переехал в шапку; код оставлен.
- `ChatsController` / `MainController` — нижний отступ списка под доком/FAB.
- `TGChat` — начертание имени по непрочитанным.
- `ViewPagerTopView` — индикатор вкладок 3dp со скруглением сверху по ширине текста, подписи без капслока.
- `M3SettingsGroupDecoration` — сгруппированные (segmented) списки настроек: внешние углы 16dp, внутренние 4dp,
  промежутки 2dp, тени и разделители заменены цветом страницы, группы считаются по модели адаптера.
  Подключается `M3SettingsGroupDecoration.attach(recyclerView, adapter)` до `setAdapter`. Включено на главном
  экране настроек, «Данные и память», «Уведомления и звуки», «Конфиденциальность», экраны правил
  конфиденциальности (`SettingsPrivacyKeyController`, напр. «Время захода»), «Язык», «Перевод»,
  «Стикеры и эмодзи», «Прокси», «Настройки архива», «Использование сети», выбор набора иконок / эмодзи
  (`SettingsCloudController`), файлы логов, «Темы» (все режимы `SettingsThemeController`: темы, настройки
  интерфейса, камера), «Устройства», «Авторизованные сайты», «Заблокированные», «Использование памяти»,
  «Выход», «Папки с чатами»; во всех темах. Сегментами также считаются ползунки, строки сессий/сайтов, чатов и пользователей,
  строки кэша (`DoubleTextView`) и двухстрочные чекбоксы. Строки экранов со своими типами (`ListItem.TYPE_CUSTOM - x`)
  становятся сегментами только если экран перечислил эти типы в `attach(recyclerView, adapter, типы…)`
  («Папки с чатами»: строки папок и рекомендованных папок). `TYPE_PADDING` (нижний отступ) — вне группы.
  Перетаскивание строк (папки, прокси): поднятая строка по токенам `ListItemTokens` — скругление 16dp со всех
  сторон (fast spatial пружина), тень Level4 = 8dp (`translationZ`) и слой состояния `onSurface` 16% (fast effects);
  промежутки между группами под поднятой строкой не рисуются. Сигнал — `RemoveHelper.ExtendedCallback.onDragStateChanged`
  (подъём / отпускание, до того как строка встанет на место). Красная подложка свайпа-удаления в `SettingView`
  обрезается по форме сегмента (`M3SettingsGroupDecoration.clipToSegment`). Собственные разделители «Папок»
  (линия 0.5dp от 72dp) удалены — их заменили промежутки 2dp. Отступ `TYPE_EMPTY_OFFSET_SMALL` (4dp цвета страницы),
  заглушка ошибки `TYPE_EMPTY` и заглушки «нет сеансов / сайтов» явно помечены в `kindAt()` как не входящие
  в группу. При смене темы декорация подписана на `ThemeManager` (пока список на экране) и перерисовывает
  список: иначе промежутки оставались цвета прежней темы до прокрутки. Если список начинается сразу с группы
  (без заголовка секции), над первой карточкой отступ 16dp от шапки (как боковые поля; **наше** решение),
  с учётом строк-отступов, уже стоящих сверху.
  Фон строки оборачивается (исходный drawable хранится внутри обёртки) и возвращается при откреплении строки
  (recycling), чтобы переиспользованная строка другого типа получила свой фон.
  `TYPE_INFO` (текст на подложке) — тоже сегмент. Перед подключением нового экрана проверить, что все его
  типы строк есть в `kindAt()`.
- Цвета групп (решение владельца — буквальная схема ролей M3, все темы): страница и шапка — `surface`,
  карточки групп — `surfaceContainer` (на ступень плотнее страницы). Шапка при прокрутке цвет не меняет
  (решение владельца, отступление от M3 «on scroll the container changes to surface container»), тени нет. Monet: роли системы; остальные темы: роли, рассчитанные из пресета (`M3.compute`).
- `TogglerView` — переключатель M3 во всех местах приложения и во всех темах (токены `SwitchTokens`): трек
  52×32dp, ручка 16dp выкл / 24dp вкл / 28dp при нажатии строки, без тени; выключенное состояние —
  трек `onSurface` 12%, ручка `onSurface` 38% / `surface`. «Негативный» вариант (разрешено/запрещено, права
  участников) — значки ✕ / ✓ в ручке 24dp. Замок (значение нельзя изменить) рисуется как выключенный
  переключатель: значок в ручке должен показывать только вкл/выкл (Switch: «Avoid … non-binary icons»), поэтому
  значка замка в ручке нет — **наше** решение. Красно-зелёная раскраска «негативного» варианта и цвета
  `togglerPositive*/togglerNegative*` из редактора тем больше не используются. Ширина в `SettingView` — 72dp,
  место под текст — 50dp. Обработка нажатий не менялась.
- `ViewPagerHeaderViewCompact.setM3Divider` — разделитель вкладок 1dp `outlineVariant` под индикатором
  (по нижнему краю полосы вкладок), включён только для главной шапки, во всех темах.
- Бейджи вкладок папок (`MainController.UnreadCounterColorSet`) — `error` / `onError` во всех темах.

- Главный экран (шапка и док), только `MainController` и новые виджеты; общие `HeaderView`/`HeaderFilling`
  меняются только через флаги экрана (`useHeaderShadowLine`, сдвиг `moreWrap` на `trailingGap`):
  - телефон: шапка — `M3MainTitleView` («Vibegram X» + эмодзи-статус, по умолчанию 🚀) и карандаш с меню
    «Написать»; док `MainNavigationBar` — плавающий вертикальный: Поиск → Чаты → Звонки → Контакты →
    Настройки (аватар). При прокрутке списка док сворачивается в стрелку ↑ (`ITEM_SCROLL_TOP`), а Поиск,
    Звонки, Контакты и аватар переезжают в шапку перед карандашом (`mainMenus`, обновляются во всех меню —
    у левой панели планшета своё меню). На узкой ширине заголовок уступает место: сначала прячется эмодзи,
    потом шрифт 22 → 18sp, потом заголовок скрывается целиком;
  - планшет: шапка левой панели — пилюля поиска `M3SearchBarView` с подписью «Vibegram X» (48dp вместо 56dp,
    чтобы влезть в шапку 56dp) и карандаш; док — горизонтальная панель внизу панели списка, не сворачивается.
    Подсветка нажатия пунктов дока обрезается по пилюле индикатора. Пустая правая панель (чат не открыт) — просто
    фон страницы без текста (решение владельца: подпись «Vibegram X» остаётся слева, в пилюле);
  - поверхности и шапки по ролям M3 во всех темах и раскладках (решение владельца: «окрашивание по гайдлайнам
    для всех тем; Monet — схема системы, классические — цветовые пресеты»). `Theme.chromeColor` подменяет при
    чтении через `Theme`: filling, background, headerBackground → `M3.surface`; headerText/headerIcon →
    onSurface; headerTabActive* → primary; headerTabInactiveText → onSurfaceVariant; statusBar → прозрачный;
    `Theme.needLightStatusBar` = !isDark. `M3` берёт исходный filling пресета напрямую из делегата (без
    рекурсии). Навигация (рейл, док, вкладки папок внизу) — surfaceContainer (`M3.roleDrawable`). Шапка при
    прокрутке не перекрашивается (владелец отказался от surface → surfaceContainer; механизм удалён, пилюля
    поиска — постоянно surfaceContainerHigh); тень под шапкой не рисуется (M3: «no drop shadow»). Раньше шапка была
    filling пресета, а страница — background пресета: в Monet White это давало белую шапку над бежевой страницей.
    Превью тем и принудительные темы (просмотр медиа) читают делегат напрямую и не затрагиваются;
    `TextColorSetThemed` без принудительной темы читает через `Theme` (`themedColor`). Режим постоянный:
    при переключении на лету слушатели текста (`MODE_TEXT_COLOR`, `hasColorChanged`) не перекрашивали уже
    созданные заголовки. Рейл перерисовывает пункты при смене темы (`ThemeInvalidateListener`). При
    складывании/раскладывании система сбрасывает appearance окна (значки статус-бара становились белыми) уже после
    `onConfigurationChanged`,

## 9. Регрессии

### Вылет при переходе на «Контакты» после смены режима окна (исправлено)

- Стек: `NullPointerException: TextView.setId` в `HeaderView.genTitle` ← `HeaderView.setTitle` ←
  `NavigationController.navigateTablet` ← `MainController.openNavigationSection` (пункт «Контакты»).
- Минимальный сценарий: узкое окно → открыть «Настройки» и остаться → раскрыть до двух панелей → «Контакты».
- Причина: `applyPreview()` меняет местами `textTitle`/`textPreview`. После перехода между двумя экранами со
  своей шапкой (Чаты → Настройки) обычный текстовый заголовок становится `null`. Анимированный путь создаёт
  его заново в `genPreview()`, а путь двух панелей (`navigateTablet → setTitle → genTitle`) — нет.
  Это дефект существующего кода планшетной навигации (`HeaderView`/`NavigationController` редизайном не
  менялись), проявившийся при смене режима; историческую сборку отдельно не проверяли.
- Исправление: `HeaderView.genTitle` создаёт `textTitle`, если его нет (как `genPreview` для `textPreview`).
- Проверено на Fold сменой размера окна (`wm size`), не физическим складыванием: сценарий выше; Настройки ↔
  Контакты ×2 → Чаты в двух панелях; узкое окно Настройки → Back → Настройки → раскрыть → Контакты;
  Контакты → узкое окно → Back → раскрыть → Настройки → Контакты → Back. Падений нет, у «Контактов»
  заголовок и кнопка «Назад» на месте.

### Вылет после входа: `UnsupportedOperationException` в `ViewPagerTopView.setItemAt` (исправлено)

- Список вкладок без папок был `Collections.singletonList`, а счётчик непрочитанных при смене ширины
  вызывает `List.set`. Список вкладок для `ViewPagerTopView` должен быть изменяемым (`ArrayList`).

### Иконки дока не переезжали в шапку после складывания/раскладывания Fold (исправлено)

- Код помнил только последнее меню шапки; у левой панели планшета своя шапка. Кнопки обновляются во всех
  `mainMenus` по id. Проверка: `adb shell cmd device_state state 0|3`, затем `state reset`.

### После складывания/раскладывания пропадали «Vibegram X» и «Назад» (исправлено)

- Сценарии: (1) сложено: открыть чат → разложить → закрыть чат в двух панелях → сложить: в шапке главного
  экрана нет «Vibegram X»; (2) сложено: открыть чат и вернуться → разложить → открыть чат → сложить: у чата нет
  «Назад» (в правой панели её тоже не было). «Иногда» — потому что зависит от того, какой была последняя
  анимированная смена экрана в одной панели.
- Причина: анимированный переход оставляет уходящий заголовок (`M3MainTitleView` переиспользуется) и
  погасшую кнопку «Назад» прозрачными и сдвинутыми; восстанавливает их только следующий анимированный
  переход. Пути двух панелей без анимации (`navigateTablet`, выход из двух панелей в `updateTabletLayout`)
  вызывали `setTitle`, который делает кнопку видимой, но не трогает alpha/сдвиг.
- Исправление: `HeaderView.resetTitleTransition(item)` возвращает заголовок и кнопку «Назад» в покой
  (alpha 1, без сдвига; сдвиг по Y заголовка не трогается в popup-режиме); вызывается после `setTitle` в
  `navigateTablet` (заменяет прежний сброс одной `getCustomHeaderCell()`) и при возврате главного экрана в одну
  панель в `updateTabletLayout`.
- Проверено на Fold через `cmd device_state state 0` / `state reset`, текущая (тёмная) тема: оба сценария до
  исправления воспроизводились (пиксели шапки + uiautomator), после — заголовок и стрелка на месте в сложенном
  и разложенном виде; нажатие «Назад» в сложенном чате возвращает к списку с заголовком; Настройки и Контакты в
  правой панели и Контакты после складывания — со стрелкой. Падений нет.

### Вылет при открытии поиска после смены раскладки с открытым поиском (исправлено)

- Стек: `IllegalStateException: The specified child already has a parent` в `HeaderView.genPreview` ←
  `openPreview` ← `transform` ← `HeaderView.openSearchMode` ← `MainController.openMainSearch`.
- Сценарий: две панели, открыть поиск → узкое окно (`wm size 1200x1848`) или сложить → разложить → открыть
  поиск ещё раз. С чатом в правой панели — то же.
- Причина: поле поиска (`searchHeaderView` контроллера переиспользуется) оставалось в шапке, где его открыли,
  а флаг поиска контроллера — включённым; при переносе главного экрана в другую шапку (`TabletNavigationLayout.
  setMain`/`clearMain`) поле не снималось, и `genPreview` удалял его через `removeView` не того родителя.
- Исправление: перед сменой шапки главного экрана поиск и выделение закрываются без анимации
  (`TabletNavigationLayout.leaveTransformModes`); `genPreview` удаляет вид из фактического родителя.

## 11. Как получить текст гайдлайнов

m3.material.io — одностраничное приложение; текст страниц приходит JSON-ом из
`/_dsm/content/m3/<carbonVersion>/<fileId>.json`, таблица страниц и версия — в `/static/angular/main.*.js`.
Скрипт загрузки в Markdown хранится вне репозитория (навык Hermes `material3-guidelines`).
